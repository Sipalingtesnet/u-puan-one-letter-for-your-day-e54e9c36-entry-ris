A one-character entry for the [One Letter for Your Day bounty](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36).

## What it does

`main.py` creates `/output/entry.txt` and writes exactly one uppercase letter,
UTF-8, with no word, no gloss, no punctuation and no trailing newline. The
letter is a string literal in the program, so every run is deterministic and
makes no network calls.

The letter stands for one word describing the day. Here it stands for a day
that was spent standing still in a line that barely moved — the kind of day
that is over and you cannot point to a single thing you did.

The entry is the letter alone, so the word has to be carried by the initial:
the sharper the letter's fit to its word, the better the day reads.

## Run it

Requires Python 3.13 (standard library only, nothing to install).

```sh
python3 main.py
cat /output/entry.txt
```

Expected: one letter, and the file is exactly one byte — no trailing newline.
